This is local staging material. Nothing has been uploaded, assigned a public
license or given a DOI. Author metadata is intentionally deferred.

Contents
1. sod1fep-forensic-review.tar.gz: unchanged historical September 14 release.
   Its original SHA256 sidecar and internal 1217-entry manifest are preserved.
2. paper_source_snapshot.tar.gz: base-commit source with explicitly inventoried
   local paper revisions. SOURCE_SNAPSHOT.json gives base commit, overlay hashes
   and every source-file hash. It is not a clean committed-source release.
3. later_f64a_evidence.tar.gz: 60 cumulative v2 energy arrays (20 x 15001 each),
   late-window/raw-energy/lambda audit products where present. Main saved v1/v2
   reports, plans and temporal audit are also in the source snapshot under docs/.
4. SHA256SUMS and JSON inventories: exact file identities for transfer checks.
5. deposit_metadata.json: machine-readable draft metadata; missing fields are
   intentionally null or empty, not invented.

Verify all outer files with: shasum -a 256 -c SHA256SUMS
Verify the historical bundle before extraction using the repository command:
  python -m src.analysis.forensic_release --verify sod1fep-forensic-review.tar.gz

then overlay the source snapshot and later evidence in that same fresh directory.

project/docs/manuscript/SUBMISSION_CHECKLIST.md. The Word builder needs

contain earlier reduced-potential samples, but do not recover the original v1
